# 校园网自动登录

掉线自动重连校园网的 Windows 桌面 App。后台静默运行，断网自动重连，设置界面简洁清晰。

适配锐捷 eportal 校园网认证（如 CQUST-T 等高校网络）。

## 功能特性

- **断线自动重连**：后台守护进程持续监听网络状态，掉线后自动登录
- **极速启动（开机自启）**：开机即自动联网，锁屏状态下就已后台运行（**需管理员授权一次**）
- **免管理员权限**：安装、运行均不需要管理员（仅开启「极速启动」需授权一次）
- **本机存储**：账号密码仅在本机混淆存储，不联网上传
- **缓存自清理**：卸载时自动清理 C 盘产生的运行缓存

## 安装

运行 `Setup_校园网自动登录_v1.2.0.exe`：

1. 选择安装路径（默认 `D:\校园网自动登录`，可改）
2. 点击「安装」

> 安装向导已精简，不再出现「选择附加任务」「开始菜单文件夹」页面。
> **默认创建桌面快捷方式**，不创建开始菜单项。

若提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**（未签名软件的正常提示）。

## 使用

1. 打开"校园网自动登录" → 填账号密码 → **保存设置**
2. **启动后台服务** → 勾选 **极速启动** → 在弹出的 UAC 窗口点「是」（仅需授权一次）
3. 验证：断 WiFi 重连，日志区 15 秒内出现"[登录] 成功 → [网络] 已联网"

> **极速启动**以系统计划任务方式开机自动运行，早于用户登录：
> 开机后无需等待，锁屏状态下就已后台联网，网络一通立即认证
> （与 Wallpaper Engine 的优先启动同一思路）。

## 退出程序

点击界面右下角的「退出」按钮：

- 若 **未开启**「后台服务」和「极速启动」：直接退出，无弹窗
- 若 **已开启** 其中任意一项：弹出确认框，列出当前开启的功能
  - **留在设置**：关闭弹窗，继续留在界面
  - **仍要退出**：立即退出（不会二次弹窗）

> 标题栏的关闭按钮（×）已禁用，统一走「退出」按钮，避免误关。

## 卸载

自带卸载程序，入口：控制面板 / 安装目录里的 `unins000.exe`。

卸载程序会**自动先停止后台守护服务**再删除文件，并一并清理运行痕迹（无需手动操作）：

- **手动卸载会删**：程序、桌面快捷方式、注册表信息、安装目录下所有运行时文件（`config.json` 账号配置、`logs\` 日志、`daemon.pid`、`status.json`、`gui.port`、`gui.url`）、极速启动计划任务（`CampusAutoLoginBoot`，含旧版遗留的 `CampusAutoLogin`）、`%LOCALAPPDATA%\校园网自动登录_WebView2` 缓存目录
  - `CampusAutoLoginBoot` 以 SYSTEM 身份创建，删除需管理员。非管理员卸载时会跳过，
    可在管理员命令行手动执行：`schtasks /delete /tn "CampusAutoLoginBoot" /f`
- **覆盖升级会保留**：`config.json`（账号）、`logs\`（日志），升级后无需重新填写账号

## 升级

直接运行新版安装包即可**覆盖升级**：自动卸载旧版 → 安装新版，配置（`config.json`）与日志自动保留。

（若之前手动删过安装目录，安装包会自动清理残留注册表后正常覆盖。）

## 常见问题

- 双击没反应 → 杀毒软件拦截，加白名单
- 登录失败 → 点【打开日志文件夹】把当天日志发给开发者
- 更新 → 直接运行新版安装包覆盖，配置保留
- 界面显示成别的网站的内容 →
  本程序的设置页**不再使用固定端口**，每次启动由系统分配空闲端口，
  因此不会与你本地部署的其他网站冲突。若仍遇到，请确认已升级到本版本。
- 开机后要等很久才联网 →
  勾选**极速启动**（开机即运行，不必等登录）；同时守护进程已把耗时的
  WiFi 扫描放到后台线程，并在开机后前 60 秒用 5 秒短间隔抢跑。

## 技术说明

- 语言：Python + pywebview（WebView2 / edgechromium 渲染界面）
- 部署方式：**onedir**（程序与依赖一起放在安装目录），不再解压到 `%TEMP%\_MEIxxxxxx` 临时目录，因此退出时不会出现 "Failed to remove temporary directory" 警告
- 设置页通信：本机 HTTP 服务，**端口每次启动动态分配**（不再固定 8765），并带随机访问令牌校验
  - 避免与用户本地部署的其他网站抢端口（Windows 的 `SO_REUSEADDR` 允许端口抢占，会造成"串台"）
  - 同时阻止外部网页跨域驱动本程序的接口
- 自启实现：**系统计划任务**（`ONSTART` 触发、SYSTEM 身份运行），不再是注册表 `Run` 键
  - `Run` 键要等桌面就绪才触发且受 Windows 启动项错峰延迟影响，计划任务开机即触发
  - 旧版（v1.2.0 早期构建）的登录级任务 `CampusAutoLogin` 已废弃，新版启动时会自动清理
- 打包：PyInstaller + Inno Setup 安装包
- 版本：v1.2.0
