校园网自动登录 v1.1.0 发布包说明
================================

本压缩包包含三类内容：
1. Setup_校园网自动登录_v1.1.0.exe —— 最终安装包，可直接发给他人安装（免管理员权限）。
2. 源码（app.py / campus_core.py / daemon.py / gui.py / config.json 等）—— 可上传 GitHub。
3. build/ 目录（setup.iss / CampusLogin.spec / version_info.txt / icon.ico / stage/）—— 用于修改并重打安装包。

如何重打安装包（Windows）：
- 安装 Python 3.13，创建虚拟环境并安装依赖：
    python -m venv build/venv
    build/venv/Scripts/pip install pyinstaller pywebview
- 生成 onedir 程序：
    build/venv/Scripts/pyinstaller build/CampusLogin.spec --noconfirm
  （产物在 build/dist/CampusLogin/，将其内容复制到 build/stage/app/）
- 编译安装包（需 Inno Setup，本机位于 D:\inno\ISCC.exe）：
    D:\inno\ISCC.exe build/setup.iss
  产物输出到 output/Setup_校园网自动登录_v1.1.0.exe

说明：
- build/venv 体积约 55MB，未放入本压缩包，请按上面命令重建（也可保留本机 D:\CampusLogin\build\venv 直接复用）。
- build/stage/app 已是编译好的 onedir 程序；若只调整安装向导文字（setup.iss），可直接重跑 ISCC，无需重新编译 Python。

## 自定义品牌

- 应用图标（安装包、桌面快捷方式、卸载 ico）：`build/icon.ico`
  替换为其它 .ico 后，重跑 Inno Setup 编译即可（无需重打 exe）。
  生成多尺寸 ico 可用 Pillow：

      python -c "from PIL import Image; img=Image.open('新图.png'); img.save('icon.ico', format='ICO', sizes=[(16,16),(24,24),(32,32),(48,48),(64,64),(128,128),(256,256)])"

- 主界面顶部 logo：`gui.py` 顶部的 `data:image/png;base64,...`（替换整段字符串即可）。
- 主题色：`gui.py` 中 `:root` 的 CSS 变量。
- 版本号与公司名：`build/version_info.txt`。
- 安装包元数据：`build/setup.iss` 顶部 `#define MyApp*`。
